# GKS-U Student GPA & Grade Calculator

Welcome to my first programming project! This is a Python command-line application designed to calculate a student's average percentage, assign a standard **4.0 scale GPA**, and evaluate their eligibility status for the **GKS-U scholarship cut-off (80%)**.

## Features
- Inputs marks for Physics, Chemistry, and Mathematics.
- Calculates overall average percentage.
- Automatically maps the percentage to a 4.0 scale GPA.
- Provides an instant evaluation of GKS-U academic eligibility.

## How to Run Locally
1. Download `main.py` from this repository.
2. Open your terminal or PowerShell in the file's folder.
3. Run the application using:
   ```bash
   python main.py
   ```
